# Referencia: Atajos de Teclado

> **Use esta lista** para trabajar más rápido sin usar el ratón. Especialmente útil para personas mayores que prefieren el teclado.

## Atajos principales

| Atajo | Acción |
|-------|--------|
| `Ctrl + K` | Abrir la **paleta de comandos** (buscar cualquier cosa) |
| `Ctrl + S` | Guardar (en fichas de costo, formularios) |
| `Ctrl + P` | Imprimir |
| `Ctrl + F` | Buscar dentro de una página |
| `Ctrl + +` | Acercar (hacer la letra más grande) |
| `Ctrl + -` | Alejar (hacer la letra más pequeña) |
| `Ctrl + 0` | Volver al tamaño normal |
| `Ctrl + C` | Copiar |
| `Ctrl + V` | Pegar |
| `Ctrl + X` | Cortar |
| `Ctrl + Z` | Deshacer |
| `Ctrl + Y` | Rehacer |
| `F5` | Refrescar la página |
| `Escape` | Cerrar menús, modales, volver atrás |

## Navegación rápida (Ctrl + número)

| Atajo | Va a |
|-------|------|
| `Ctrl + 1` | Inicio (dashboard) |
| `Ctrl + 2` | Vender (POS) |
| `Ctrl + 3` | Inventario (Stock) |
| `Ctrl + 4` | Módulo IPV (En desarrollo, administradores) |
| `Ctrl + 5` | Fichas de Costo |
| `Ctrl + B` | Mostrar/ocultar la barra lateral |
| `Ctrl + Shift + H` | Abrir el Centro de Ayuda |
| `Ctrl + /` | Ver la lista de atajos de teclado |

> 💡 **Consejo**: Memorice primero estos cuatro: 1=Inicio, 2=Vender, 3=Inventario, 5=Fichas de Costo. Todo lo demás lo encuentra con `Ctrl + K`.

## Atajos del POS (caja)

| Atajo | Acción |
|-------|--------|
| `F1` | Abrir la ayuda de atajos del POS |
| `F2` | Enfocar la barra de búsqueda de productos |
| `F9` | Cobrar (procesar el checkout) |
| `Ctrl + Enter` | Cobrar (alternativa mientras escribe en un campo) |
| `Enter` | Confirmar (depende del contexto) |
| `Escape` | Cancelar operación actual |

## Atajos universales del navegador

Estos funcionan en cualquier página web, no solo en CostPro:

| Atajo | Acción |
|-------|--------|
| `Ctrl + T` | Abrir nueva pestaña |
| `Ctrl + W` | Cerrar pestaña actual |
| `Ctrl + Tab` | Cambiar a la siguiente pestaña |
| `Ctrl + Shift + T` | Reabrir la última pestaña cerrada |
| `Alt + Flecha izquierda` | Volver a la página anterior |
| `Alt + Flecha derecha` | Avanzar a la siguiente página |
| `Ctrl + D` | Agregar a favoritos |
| `Ctrl + H` | Abrir historial del navegador |

## Cómo usar los atajos

### Para presionar `Ctrl + K`:
1. Mantenga presionada la tecla **Ctrl** (la de abajo a la izquierda del teclado).
2. Sin soltarla, presione una vez la tecla **K**.
3. Suelte ambas teclas.
4. Se abre la paleta de comandos.

### Para presionar `Ctrl + 2`:
1. Mantenga presionada la tecla **Ctrl** (la de abajo a la izquierda del teclado).
2. Sin soltarla, presione una vez la tecla **2** (en el teclado de números de arriba, no en el lateral).
3. Suelte ambas teclas.
4. Va directo a Vender (POS).

### Para presionar `Ctrl + Shift + H`:
1. Mantenga presionada **Ctrl**.
2. Sin soltarla, mantenga presionada **Shift** (la flecha hacia arriba).
3. Sin soltar ninguna, presione **H**.
4. Suelte todas.

## Preguntas frecuentes

**¿Los atajos funcionan en Mac?**
- Casi todos. En Mac, use **Cmd** (⌘) en lugar de **Ctrl**.
- `Cmd + K`, `Cmd + S`, etc.
- Para los atajos con **Alt**, en Mac use **Option** (⌥).

**¿Puedo cambiar los atajos?**
- No, son fijos. Pero puede usar siempre la paleta de comandos (Ctrl+K) que es más fácil.

**¿Los atajos funcionan en celular?**
- No, los celulares no tienen teclado físico. Use el menú lateral y los botones.

**¿Cómo memorizo los atajos más importantes?**
- Empiece por estos 5:
  1. **Ctrl + K**: paleta de comandos (lo más útil).
  2. **Ctrl + Shift + H**: ayuda.
  3. **Escape**: cerrar / cancelar.
  4. **Ctrl + +**: agrandar letra (para personas mayores).
  5. **F5**: refrescar.

**¿Qué hago si presiono un atajo por error y pasa algo raro?**
- Presione **Escape** primero. Cierra la mayoría de las cosas.
- Si no funciona, presione **F5** para refrescar la página.
- Si eso tampoco, cierre la pestaña con **Ctrl + W** y vuelva a abrir CostPro.
